{% include base_path %} {% comment %} These three are separate files on purpose: main.min.js is a committed uglify bundle that only changes when you run `npm run build:js`, so keeping site behaviour out of it means editing these takes effect immediately. The ?v= build timestamp busts browser and CDN caches on every deploy. Without it a returning visitor keeps running the previously cached copy of these files, which is exactly how a shipped fix can appear not to have shipped. {% endcomment %} {% include analytics.html %}
